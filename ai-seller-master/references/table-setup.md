# Таблицы Suvvy — универсальная настройка

Официально: столбцы / частые обновления / точный ключ → **Таблицы**. Текст / FAQ / регламент → **Вопрос—ответ** или Документы. Не класть прайс на 1000 SKU в Instructions.

Таблица пассивна, пока нет **функции** и правила в промпте: «если клиент спрашивает X — вызови функцию».

## Файл

- CSV или XLS / Google Sheets.
- Кодировка CSV: **UTF-8 без BOM** (BOM ломает имя первой колонки).
- Колонка `search_text`: склейка RU+EN+тип+описание+алиасы.
- Колонка `search_aliases`: опечатки и синонимы.
- Отдельные `name_ru` / `name_en` (или аналоги).
- Флаг наличия: `in_stock` / `availability`.
- Фото-URL в отдельных колонках, если клиент просит фото.

## Два имени функции на один CSV

Частый сбой: в UI одно имя, в промпте другое.

Решение: **два подключения одного файла**.

| # | Имя | Роль |
|---|-----|------|
| 1 | `{{primary}}_table` | основной вызов в промпте |
| 2 | `{{fallback}}` | если primary пустой |

Оба: «Получение через функцию — ON».

В `#WORKING WITH FUNCTIONS`: сначала primary, при пустоте — fallback, те же фильтры.

## Текст описания функции (UI)

Шаблон:

```
Каталог {{ЧТО}} для поиска остатков/цен. Ищи по части строки (LIKE, без регистра).

ПОИСК — передавай только название/артикул из контекста ВСЕГО диалога, не целое предложение клиента.

Порядок колонок (по очереди, пока не вернутся строки):
1) search_text
2) search_aliases
3) name_ru
4) name_en
Категория — только вместе с именем, не одно общее слово.

Примеры токенов: {{пример1}}, {{пример2}}.

Предпочитай in_stock=yes / наличие на складе. Макс 5 строк.
В ответе используй всю строку: размеры, цена, статус, фото-ссылки при запросе фото.
```

## Лестница поиска в промпте

1. Токен из **всей** переписки. Выбросить «есть ли», «в наличии», тип изделия.
2. Не искать только категорию (`мрамор`, `краска`) без имени.
3. `search_text` → aliases → RU → EN.
4. Предпочесть in-stock; если пусто — без фильтра.
5. Max 5 строк, пока не просят полный список.
6. Вся строка в ответ (включая фото).
7. Пусто после ретраев (токен → EN → опечатка) → менеджер, не «нет в базе».

Не блокировать lookup вопросом про размеры, если имя уже есть.

## Пересборка

Скрипт из исходного xlsx/каталога → CSV. После смены прайса: пересобрать → залить → проверить имена функций.

Не читать «запомненные» остатки из старых чатов.
