# Примеры применения мастера

## Новый бот с нуля

1. Собрать чаты + прайс + «как продаём».
2. Заполнить brief-template (пометить TODO).
3. Собрать пак по prompt-pack.md.
4. Залить Suvvy по чеклисту в SKILL.md Phase 4.
5. Прогнать failure-patterns.md.

## Аудит существующего Suvvy-бота

1. Скачать Instructions + список DQ + скрины провалов.
2. Сверить files-map: каждый `get_file_text` существует и включён.
3. Сверить имена таблиц с промптом.
4. CRM: large не откладывается до телефона; после сдвига чат живой.
5. Добавить bans из новых скринов, не ломая старые приоритеты.

## «Не находит в таблице»

1. Токен из всего чата, не предложение.
2. `search_text` + алиасы + RU/EN.
3. CSV без BOM.
4. Два имени функции на один файл.
5. Описание LIKE в UI.

## Конфликт правил (склад vs large)

Приоритет: **сначала масштаб**, потом сценарий визита. Large → CRM сразу, адрес можно в том же сообщении.

## Собрать нишевый пак из мастера

Скопировать структуру Phase 2. Подставить instructions-template, hard-bans-universal, wrap_sources.py, build_xlsx.py. Заменить `{{MIN_TICKET}}`, имена таблиц, адрес, out of scope. Не копировать камень/200к вслепую в другую нишу — только структуру.

## Аудит имён

Каждый `get_file_text("…")` в paste-промпте существует в Suvvy, тумблер on, title без лишнего пробела. Primary и fallback таблиц названы как в UI. CRM одно место (DQ Integrations), старые webhook-имена вычищены из sources.
